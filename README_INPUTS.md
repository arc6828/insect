# ⚙️ พารามิเตอร์นำเข้าและข้อกำหนดการประมวลผลสำหรับการทดลอง (Experimental Inputs & Preprocessing Specifications)

เอกสารนี้รวบรวมข้อกำหนดทางเทคนิคทั้งหมดที่เกี่ยวกับพารามิเตอร์การเตรียมภาพนำเข้า (Data Preprocessing), เวิร์กโฟลว์การขยายข้อมูล (Data Augmentation) และค่าตัวแปรระดับสูง (Hyperparameters) ที่ใช้ในการฝึกสอนสถาปัตยกรรมโครงข่ายประสาทเทียมในการทดลองนี้

---

## 🖼️ 1. การเตรียมรูปภาพและสัดส่วนข้อมูล (Data Preprocessing & Splitting)

เพื่อรักษากายภาพภายนอกของแมลงศัตรูข้าวไทยไม่ให้บิดเบี้ยวและรักษาเสถียรภาพในการลู่เข้าของโมเดล การจัดการรูปภาพในอินพุตไพป์ไลน์กำหนดไว้ดังนี้:

* **ข้อมูลนำเข้าเป้าหมาย (Target Input Shape):** ขนาด $224 \times 224$ พิกเซล ระบบสี RGB (3 แชนเนล)
* **เทคนิคการปรับขนาดเล็ตเตอร์บ็อกซ์ (Letterbox Resizing with Padding):**
  * เพื่อหลีกเลี่ยงการบีบอัดรูปภาพต้นฉบับซึ่งจะทำลายสัดส่วนทางสัณฐานวิทยาของแมลง (Morphological Distortion) เช่น ความสั้นยาวของขา สัดส่วนหาง หรือปีก
  * รูปภาพจะถูกย่อส่วนโดยรักษาอัตราส่วนดั้งเดิม (Aspect Ratio) โดยยึดด้านที่ยาวที่สุดให้พอกล่อง $224 \times 224$ พิกเซล
  * เติมขอบข้างที่เหลือ (Padding) ด้วยค่าสีขาว (RGB: `255, 255, 255`) เพื่อสร้างภาพจัตุรัสที่สมบูรณ์
* **สัดส่วนการจัดแบ่งข้อมูล (Data Splitting):**
  * **ชุดข้อมูลฝึกสอน (Training Set):** 80% (สำหรับปรับค่าน้ำหนักพารามิเตอร์โมเดล คิดเป็นจำนวน 1,416 ภาพ)
  * **ชุดข้อมูลตรวจสอบ (Validation Set):** 20% (สำหรับทดสอบพฤติกรรมการเรียนรู้จริง คิดเป็นจำนวน 347 ภาพ)

---

## 🔄 2. การเพิ่มพูนข้อมูลแบบสุ่ม (Data Augmentation Parameters)

เนื่องจากชุดข้อมูลมีปริมาณจำกัด จึงประยุกต์ใช้ Keras `ImageDataGenerator` เพื่อทำ Augmentation ในเวลาจริงเพื่อจำลองความหลากหลายของแสงเงาและมุมกล้องของเกษตรกรในการถ่ายภาพจริงในแปลงนาข้าว:

* **การสุ่มหมุนภาพ (Rotation Range):** $\pm 20$ องศา (เพื่อแก้ปัญหาภาพถ่ายแมลงที่หันหัวในทิศทางต่างกัน)
* **การสุ่มซูมภาพ (Zoom Range):** $\pm 10\%$ (จำลองระยะใกล้ไกลในการยืนถ่ายภาพของเกษตรกร)
* **การสุ่มเลื่อนตำแหน่งภาพ (Width / Height Shift):** $\pm 10\%$ (จำลองแมลงที่ไม่ได้อยู่จุดกึ่งกลางเฟรมภาพพอดี)
* **การสุ่มความสว่าง (Brightness Range):** $\pm 10\%$ (ช่วงสเปกตรัมแสง `[0.9, 1.1]` เพื่อจำลองความเข้มแสงแดดในแปลงนาช่วงเวลาต่าง ๆ)
* **การพลิกรูปภาพตามแนวแกนนอน (Horizontal Flip):** เปิดการใช้งาน (True)

## 🔬 3. ค่าพารามิเตอร์การฝึกสอนโมเดล (Model Hyperparameters & Training Phases)

กระบวนการทดลองใช้วิธีการเรียนรู้แบบถ่ายโอนสองขั้น (Two-Phase Transfer Learning) บนโมเดล `MobileNetV2`, `EfficientNetB0` และ `ResNet50V2` ซึ่งการตั้งค่าในแต่ละเฟสสรุปได้ดังนี้:

| พารามิเตอร์เชิงเทคนิค (Hyperparameter) | เฟสที่ 1: การสกัดลักษณะเด่น (Feature Extraction) | เฟสที่ 2: การปรับจูนละเอียด (Fine-Tuning) |
| :--- | :--- | :--- |
| **น้ำหนักตั้งต้น (Initial Weights)** | ImageNet Pre-trained | น้ำหนักของโมเดลที่บันทึกหลังจากเสร็จสิ้นเฟสที่ 1 |
| **การตรึงน้ำหนักตัวแบบฐาน (Base Trainable)** | ตรึงค่าน้ำหนัก (`base_model.trainable = False`) | ปลดล็อกทั้งหมด (`base_model.trainable = True`) |
| **โครงสร้างส่วนหัวต่อขยาย (Classification Head)** | Global Average Pooling 2D<br>Dropout (50%)<br>Dense (256 Nodes, ReLU)<br>Dense (17 classes, Softmax) | คงเดิมจากผลลัพธ์ของเฟสที่ 1 (จูนไปพร้อมโครงข่ายหลัก) |
| **ตัวปรับค่าน้ำหนัก (Optimizer)** | Adam | Adam |
| **อัตราการเรียนรู้ (Learning Rate)** | $10^{-4}$ | $10^{-5}$ (ใช้ค่าต่ำมากเพื่อถนอมความรู้สากลเดิมของภาพ) |
| **จำนวนรอบสูงสุด (Max Epochs)** | 30 Epochs | 20 Epochs |
| **กลไกการยุติการฝึกสอนล่วงหน้า (Early Stopping)** | ปิดการทำงาน (รันครบถ้วน 30 Epochs) | **เปิดการทำงาน**<br>- ตรวจสอบ: `val_loss`<br>- Patience: 10 Epochs (หากค่าสูญเสียตรวจสอบไม่ลดลงติดต่อกัน 10 รอบจะสั่งหยุดทันที) |
| **ฟังก์ชันความสูญเสีย (Loss Function)** | Categorical Crossentropy | Categorical Crossentropy |
| **เมตริกวัดผล (Metrics)** | Accuracy (ความแม่นยำ) | Accuracy (ความแม่นยำ) |
