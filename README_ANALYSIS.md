# 📊 รายงานวิเคราะห์ผลการฝึกสอนโมเดลและการเปรียบเทียบเชิงลึก (Model Training Analysis)

รายงานฉบับนี้วิเคราะห์เปรียบเทียบประสิทธิภาพและการลู่เข้าของโมเดล **MobileNetV2**, **EfficientNetB0**, และ **ResNet50V2** ที่ผ่านกระบวนการฝึกสอนแบบสองเฟส (**Two-Phase Transfer Learning**) บนฐานข้อมูลจำแนกแมลงศัตรูข้าวไทย

## 🔬 บทวิเคราะห์และข้อค้นพบทางวิชาการ (Academic Evaluation)

### 1. EfficientNetB0: ความถูกต้องสูงสุดในเฟสสกัดลักษณะเด่น (Feature Extraction)
* **พฤติกรรม**: โมเดลทำงานได้อย่างยอดเยี่ยมที่สุดในเฟสแรก โดยทำ Validation Accuracy สูงสุดถึง **91.64%** และ Validation Loss ต่ำสุดเพียง **0.3243** แสดงว่าโครงสร้างแบบ Compound Scaling ของ EfficientNet มีประสิทธิภาพในการจัดจำแนกแมลงได้อย่างดีแม้ไม่ได้เปิดฝึกสอนชั้นล่าง
* **ปัญหาการเทรน (Overfitting)**: ในเฟสสอง (Fine-Tuning) โมเดลเกิดอาการ Overfitting สูงมาก โดยค่า Loss บนชุด validation สูงขึ้นเป็น **1.8639** และความแม่นยำตกลงมาอยู่ที่ **85.88%** ส่งผลให้ระบบสั่ง Early Stopping ทันที
* **สรุปการนำไปใช้**: แนะนำให้เซฟค่าน้ำหนักโมเดล (Best Weights) จากเฟส Feature Extraction เป็นหลักเพื่อนำไปใช้งานจริง เนื่องจากให้ค่าความแม่นยำดีที่สุดและมีขนาดโมเดลเบาที่สุด (~4.2 MB)

### 2. ResNet50V2: เสถียรภาพและพัฒนาการดีที่สุดในเฟส Fine-Tuning
* **พฤติกรรม**: เป็นโมเดลเดียวที่ตอบสนองเชิงบวกต่อการจูนละเอียดเชิงลึก (Fine-Tuning) อย่างมั่นคง โดยความถูกต้องบนชุดตรวจสอบถูกพัฒนาขึ้นเรื่อยๆ จาก **85.01%** ไปเป็น **89.05%** (สูงสุดแตะที่ **89.34%** ในรอบที่ 18) และค่าสูญเสียลู่เข้าหาค่าต่ำสุดที่ **0.3778** 
* **สรุปการนำไปใช้**: เหมาะสำหรับระบบที่ต้องการความทนทานและความคงเส้นคงวาในการเรียนรู้เพื่อเพิ่มความถูกต้องได้ตลอดการปรับน้ำหนัก เหมาะสมหากต้องการพัฒนาความแม่นยำระยะยาวด้วยขนาดโมเดลที่ใหญ่ขึ้น

### 3. MobileNetV2: โมเดลขนาดเล็กสำหรับการติดตั้งในอุปกรณ์ความจุต่ำ
* **พฤติกรรม**: แสดงประสิทธิภาพคงที่ โดยประคับประคอง Validation Accuracy ได้ที่ระดับ **85%** ตลอดทั้งเฟสแรกและเฟสสอง การ Fine-Tuning ไม่ทำให้ผลดีขึ้นอย่างชัดเจน (ลดลงมาอยู่ที่ **84.73%**)
* **สรุปการนำไปใช้**: เหมาะสำหรับการนำไปจำลองใช้งานจริงบนโทรศัพท์มือถือเครื่องเกษตรกรที่มีสเปกเครื่องจำกัดมาก เนื่องจากคำนวณและตอบสนองได้รวดเร็ว (Low Latency) และไม่เสี่ยงต่ออาการ Loss Divergence
